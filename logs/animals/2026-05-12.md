# Animals experiment log — 2026-05-12

## Setup

Dominance contest active info-gathering example. Ego agent estimates opponent parameters θ = [q, K] online via EKF while planning actions that trade off escalation cost against info gain.

Environment: `true_q=5.0`, `true_K=1.0`, `sigma_v=0.5`. Action range `[0, 2]` (ego can only escalate). MPPI planner with horizon=10, batch_size=500, num_iterations=3.

Info-gathering bonus: `λ · ½ · log(S_t / σ²_v)` where `S_t = J P J^T + σ²_v·I`, `J = [[0,0],[q̂−x1_t, K̂]]`. Fixed P through planning horizon; info signal varies because J changes as x1 evolves along rollout.

## Notes

- MPPI action clipping fix: dynamics and environment both rescale MPPI's `[-1, 1]` output to `[0, 2]` via `u = action_min + (a + 1) * 0.5 * (action_max - action_min)`. This ensures every MPPI proposal maps to a distinct escalation value; previously, negative proposals all clipped to u=0, preventing probing.
- EKF identifiability: at x1≈0, the Jacobian term `q̂−x1 ≈ q̂` makes K and q hard to separate. Higher λ forces x1 away from 0, improving identifiability.
