## Planned Experiments

**Online adaptation to new environment (mass scale shift)**

Hypothesis: Adapting only LoRAXS adapters online recovers performance in a new environment as well as adapting all dynamics parameters, using far fewer parameters.

Setup: Change environment mass scale to simulate a new deployment environment. All conditions use TD-MPC2-style online learning (1 SGD step per collected transition). Y-axis: eval reward, x-axis: online steps.

WandB project: `test_adaptation`. Each condition runs 2 seeds sequentially (1 process), 100k steps, chunk size 1000, eval every 10k steps. No final model saved.

Experiment 0 is a sanity check: full TD-MPC2 with all parameters trainable, loaded from `baseline_new`, run in the new environment with the same online learning setup as experiments 1-5 (one batch prefill with planner, no SGD burst, large chunk size). If adaptation works at all this should converge. Run before anything else. Each condition runs 3 seeds across 2 processes. No final model saved.

Training details: all conditions prefill the buffer with exactly one batch using the planner, then start online learning with no SGD burst.

Expected result: 2 ≥ 1 > 5 > 4 >> 3. Condition 1 recovers well but updating everything online is noisy and can destabilize the latent space. Condition 2 is more focused and stable. Condition 3 is the weakest low-parameter case — random subspace plus fresh adapters means both the directions and weights start uninformed. Condition 4 is significantly better because the pretrained subspace already captures meaningful dynamics directions, so a fresh R adapts quickly. Meta-learning (5) closes most of the remaining gap to condition 2.
