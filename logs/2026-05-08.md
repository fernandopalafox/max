# 2026-05-08

## CartPole Balance Environment

Added `cartpole_balance` as a second supported environment in `max/environments.py`. Uses `mujoco_playground`'s `CartpoleBalance` (dm_control-style balance task, pole starts near upright). Observation is 5D: `[cart_pos, pole_cos, pole_sin, cart_vel, pole_vel]`. Action is 1D cart force in `[-1, 1]`. Dense reward is a product of upright, centered, small_control, and small_velocity terms, bounded in `[0, 1]`. Episode length 1000. `train.py` was also made environment-agnostic (removed hardcoded "cheetah" strings).

**Code added/modified:**
- `max/environments.py` — `_make_cartpole_balance_env` factory and dispatch in `init_env`
- `scripts/train.py` — removed cheetah-specific print and default run name
- `configs/pretrain_cartpole_tdmpc2.json` — vanilla TDMPC2 config for CartPole balance, 500k steps, W&B project `pretrain_cartpole`

## CartPole Balance Pretraining — Baseline

4-seed vanilla TDMPC2 pretraining on CartPole balance, 500k steps each. Same hyperparameters as the cheetah dense baseline.

**Launch (2 GPUs, 2 batches of 2):**

```bash
for seed in 44 45; do gpu=$((seed-44)); \
  conda run -n max python scripts/train.py \
    --config pretrain_cartpole_tdmpc2.json \
    --gpu $gpu --seed $seed \
    --save-dir ./data/models/cartpole/baseline_new/run_$((seed-43)) \
    --run-name cartpole_balance_$((seed-43)) & \
done; wait
for seed in 46 47; do gpu=$((seed-46)); \
  conda run -n max python scripts/train.py \
    --config pretrain_cartpole_tdmpc2.json \
    --gpu $gpu --seed $seed \
    --save-dir ./data/models/cartpole/baseline_new/run_$((seed-43)) \
    --run-name cartpole_balance_$((seed-43)) & \
done; wait
```

W&B project: `pretrain_cartpole`, run names `cartpole_balance_1` through `cartpole_balance_4`.

Save dirs: `data/models/cartpole/baseline_new/run_{1..4}/`.

## MPPI Exploration Fix + Relaunch

Discovered the initial cartpole runs were executing the MPPI mean action directly with no noise, while TDMPC2 training samples from the converged distribution N(mean*, std*). Fixed in `planners.py` (return final_std), `rollouts.py` (add std[0]*N(0,1) to action, clip to [-1,1]), `evaluators.py` (take mean, no noise — eval mode stays clean by being a separate code path).

Killed the initial runs and moved their partial checkpoints to `data/models/cartpole/baseline_noexp/run_{1..4}/`. Relaunched the same 4-seed setup with the corrected code, same config and save dirs under `baseline_new`.

## Offline Adaptation Infrastructure

Added two new scripts and supporting rollout/environment changes for offline data collection and offline finetuning.

**Code added/modified:**
- `scripts/collect.py` — deploy a pretrained model in an environment (no training), save rollout buffer to `.npz`. Config-agnostic; env and model set via config.
- `scripts/finetune.py` — offline finetuning from a saved `.npz` buffer. Pure SGD loop (`sampler.sample_jit` → `trainer.train`), no env stepping. Trainer and dynamics type fully determined by config.
- `max/rollouts.py` — added `CollectRolloutState`, `CollectStepOutputs`, `CollectRollout`, `_make_collect_scan_step`, `init_collect_rollout` for training-free rollout loop.
- `max/environments.py` — added `cartpole_pole_length_scale` to `cartpole_balance`. Scales capsule half-length, capsule center, body CoM, and transverse inertia (×s²). Combined with existing `cartpole_pole_mass_scale` into a single modification block.
- `configs/collect_cartpole.json` — collect config for CartPole with 5x pole length.
- `configs/finetune_cartpole.json` — finetune config, tdmpc2 all-unfrozen baseline.
- `configs/finetune_cartpole_dense_ogd.json` — dense dynamics + OGD, frozen enc/critic/policy/reward.
- `configs/finetune_cartpole_dense_frozen.json` — dense dynamics + tdmpc2frozen, frozen enc/critic/policy/reward.
- `configs/finetune_cartpole_loraxs_ogd.json` — LoRA-XS rank 48 dynamics + OGD, frozen enc/critic/policy/reward.
- `configs/finetune_cartpole_loraxs_frozen.json` — LoRA-XS rank 48 dynamics + tdmpc2frozen, frozen enc/critic/policy/reward.

## CartPole Distribution Shift — Data Collection

Distribution shift: 5x pole length (1m → 5m). Natural oscillation frequency slows √5 ≈ 2.2×. The pretrained model's world dynamics predictions become stale — pole tips slower than expected, planner over-corrects. Mass scaling tried first (0.1× pole mass) but had negligible effect — mass cancels from pendulum dynamics. 2× length was too easy for the pretrained policy, 10× too extreme; settled on 5×.

**Config:** `collect_cartpole.json` — greedy policy (explore=false), 50k steps, no prefill.

```bash
conda run -n max python scripts/collect.py --config collect_cartpole.json
```

**Output:** `data/collect/cartpole/20260508_182746/buffer.npz` (50k steps, sequential).  
W&B project: `collect_cartpole`.

## LoRA-XS LR Sweep (OGD and tdmpc2frozen, 100k steps)

LR sweep over loraxs_ogd and loraxs_frozen. Base lr=3e-4 for both.

| LR | loraxs_ogd | loraxs_frozen | lora_ogd |
|----|------------|---------------|----------|
| 3e-5 | 510 | 403 | 427 |
| 1e-4 | 496 | 413 | 478 |
| 3e-4 | 485 | 415 | 525 |
| 1e-3 | 468 | 455 | 476 |
| 3e-3 | 379 | 399 | 495 |

loraxs_ogd degrades monotonically with LR — best at 3e-5. loraxs_frozen is non-monotonic, peaking at 1e-3; tdmpc2frozen's richer offline loss is unstable across LRs. Both underperform dense_ogd (524) at all tested LRs.
