# 2026-05-08

## CartPole Balance Environment

Added `cartpole_balance` as a second supported environment in `max/environments.py`. Uses `mujoco_playground`'s `CartpoleBalance` (dm_control-style balance task, pole starts near upright). Observation is 5D: `[cart_pos, pole_cos, pole_sin, cart_vel, pole_vel]`. Action is 1D cart force in `[-1, 1]`. Dense reward is a product of upright, centered, small_control, and small_velocity terms, bounded in `[0, 1]`. Episode length 1000. `train.py` was also made environment-agnostic (removed hardcoded "cheetah" strings).

**Code added/modified:**
- `max/environments.py` — `_make_cartpole_balance_env` factory and dispatch in `init_env`
- `scripts/train.py` — removed cheetah-specific print and default run name
- `configs/pretrain_cartpole_tdmpc2.json` — vanilla TDMPC2 config for CartPole balance, 500k steps, W&B project `pretrain_cartpole`

## CartPole Balance Pretraining — Baseline

4-seed vanilla TDMPC2 pretraining on CartPole balance, 500k steps each. Same hyperparameters as the cheetah dense baseline.

**Launch (2 GPUs, 2 batches of 2):**

```bash
for seed in 44 45; do gpu=$((seed-44)); \
  conda run -n max python scripts/train.py \
    --config pretrain_cartpole_tdmpc2.json \
    --gpu $gpu --seed $seed \
    --save-dir ./data/models/cartpole/baseline_new/run_$((seed-43)) \
    --run-name cartpole_balance_$((seed-43)) & \
done; wait
for seed in 46 47; do gpu=$((seed-46)); \
  conda run -n max python scripts/train.py \
    --config pretrain_cartpole_tdmpc2.json \
    --gpu $gpu --seed $seed \
    --save-dir ./data/models/cartpole/baseline_new/run_$((seed-43)) \
    --run-name cartpole_balance_$((seed-43)) & \
done; wait
```

W&B project: `pretrain_cartpole`, run names `cartpole_balance_1` through `cartpole_balance_4`.

Save dirs: `data/models/cartpole/baseline_new/run_{1..4}/`.

## MPPI Exploration Fix + Relaunch

Discovered the initial cartpole runs were executing the MPPI mean action directly with no noise, while TDMPC2 training samples from the converged distribution N(mean*, std*). Fixed in `planners.py` (return final_std), `rollouts.py` (add std[0]*N(0,1) to action, clip to [-1,1]), `evaluators.py` (take mean, no noise — eval mode stays clean by being a separate code path).

Killed the initial runs and moved their partial checkpoints to `data/models/cartpole/baseline_noexp/run_{1..4}/`. Relaunched the same 4-seed setup with the corrected code, same config and save dirs under `baseline_new`.
